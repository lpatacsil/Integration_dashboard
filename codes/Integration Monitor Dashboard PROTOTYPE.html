Severity ladder evaluated every refresh, per flow and overall

Severity is driven by integration-blocking errors only — the ones where a data object is not mapped or was skipped by indexing (customer, item / SKU, ship-to, location / store). Other NetSuite errors (Vertex, inventory, validation) are tracked on the NetSuite internal log tab with their own thresholds and do not move the severity ladder unless a threshold is crossed.

SEV 0No open blocking errors. Connector heartbeat fresh, transactions flowing both ways.
SEV 1Exactly one transaction blocked by a mapping / indexing gap.
SEV 2More than one transaction blocked by mapping / indexing, all opened today.
SEV 3More than one blocked and the oldest one has crossed into the next business day (opened before 00:00 today, still unresolved).
SEV 4Tool down. Connector heartbeat older than 30 min, or zero transactions in the last 60 min during hours when the 4-week baseline says we normally see traffic.

Severity is never lowered automatically while an incident is open — it only steps down when the blocking errors are resolved or re-run successfully.

Classifier pseudo-code


function classify(openBlocking, heartbeatAgeMin, txLast60, baselineLast60) {
  if (heartbeatAgeMin > 30 || (txLast60 === 0 && baselineLast60 > 0)) return 4;
  const n = openBlocking.length;
  if (n === 0) return 0;
  const crossedDay = openBlocking.some(e => e.openedAt < startOfToday());
  if (n > 1 && crossedDay) return 3;
  if (n > 1) return 2;
  return 1;
}

NetSuite saved-search formula same logic, if built in NetSuite


-- Formula (Text) on the integration log custom record
CASE
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'customer.*(not (found|mapped)|missing)', 'i') THEN 'MAP-CUST'
  WHEN REGEXP_LIKE({custrecord_tc_error}, '(item|sku).*(not (found|mapped)|invalid)', 'i')  THEN 'MAP-ITEM'
  WHEN REGEXP_LIKE({custrecord_tc_error}, '(ship.?to|address).*(not (found|mapped)|invalid)', 'i') THEN 'MAP-SHIP'
  WHEN REGEXP_LIKE({custrecord_tc_error}, '(location|store|shop).*(not (found|mapped))', 'i') THEN 'MAP-LOC'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'skipped|no index|not indexed', 'i')             THEN 'IDX-SKIP'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'vertex|tax (calc|service)', 'i')                THEN 'TAX-VERTEX'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'inventory|insufficient|not recognized', 'i')    THEN 'INV-ITEM'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'permission|role|insufficient privilege', 'i')  THEN 'NS-PERM'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'rate limit|429|timeout|timed out', 'i')         THEN 'API-RATE'
  WHEN REGEXP_LIKE({custrecord_tc_error}, 'duplicate|already exists', 'i')                 THEN 'DUP'
  ELSE 'VAL-DATA'
END
